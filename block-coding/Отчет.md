### 1. Постановка задачи

Цель работы — экспериментально изучить свойства блочного кодирования. Для этого необходимо:

- Использовать файл с неравномерным распределением символов (`file.txt`).
- Реализовать блочное кодирование (например, методом Хаффмана) для размеров блока \(n = 1, 2, 3, 4\).
- Вычислить избыточность кодирования на один символ входной последовательности для каждого \(n\).
- Заполнить таблицу результатов и проанализировать их, сравнив с теоретическими ожиданиями.

---

### 2. Введение

Блочное кодирование — один из методов сжатия данных без потерь, при котором входной поток разбивается на блоки фиксированной длины, и каждый блок кодируется отдельно. При увеличении длины блока можно лучше учесть статистические зависимости между символами, что позволяет приблизиться к теоретическому пределу сжатия — энтропии источника. В данной работе используется код Хаффмана, который строит оптимальные префиксные коды для заданного распределения вероятностей блоков.

---

### 3. Теоретическое описание алгоритма

**Энтропия источника** (первого порядка) вычисляется по формуле:
$$$
H = -\sum_{i} p_i \log_2 p_i,
$$
где $p_i$ — частота появления символа $i$ во входном файле. Эта величина показывает минимальное среднее количество бит, необходимое для кодирования одного символа при условии, что символы независимы.

При блочном кодировании с длиной блока $n$ файл разбивается на $N = \lfloor \frac{L}{n} \rfloor$ полных блоков (остаток отбрасывается). Для каждого уникального блока вычисляется его частота, и по этим частотам строится код Хаффмана. Средняя длина кода на один блок:
$$
L_{\text{block}} = \sum_{\text{block}} p_{\text{block}} \cdot \ell_{\text{block}},
$$

где $\ell_{\text{block}}$ — длина кода для блока. Тогда средняя длина на один символ исходной последовательности:
$$
L_{\text{sym}} = \frac{L_{\text{block}}}{n}.
$$

Избыточность кодирования на символ определяется как разность:
$$
R = L_{\text{sym}} - H.
$$

Теоретически, при оптимальном кодировании с учётом зависимостей между символами, $L_{\text{sym}}$ может оказаться меньше $H$, если истинная энтропия источника (с учётом корреляций) ниже энтропии первого порядка. В этом случае избыточность $R$ становится отрицательной, что демонстрирует эффективность блочного кодирования.

---

### 4. Описание программной реализации

Программа написана на C++. Основные этапы:

1. **Чтение файла** `file.txt` в строку.
2. **Вычисление энтропии первого порядка** $H$ на основе частот символов.
3. **Цикл по размерам блока \(n = 1,2,3,4\)**:
   - Разбиение текста на блоки длины $n$ (только полные блоки).
   - Подсчёт частот блоков.
   - Построение дерева Хаффмана для блоков (с использованием приоритетной очереди).
   - Рекурсивный сбор длин кодов для каждого блока.
   - Расчёт средней длины кода на блок, затем на символ.
   - Вычисление избыточности $R = L_{\text{sym}} - H$.
   - Освобождение памяти.
4. **Вывод результатов** в виде таблицы.

Программа корректно обрабатывает крайние случаи (например, когда все блоки одинаковы).

### 5. Анализ полученных результатов

Входной файл `file.txt` содержит последовательность символов (буквы a, b, c, d). После выполнения программы получены следующие значения:

- Энтропия источника (на символ): $H = 1.75227$ бит.

**Избыточность кодирования на один символ:**

| Размер блока n | 1         | 2         | 3         | 4          |
|----------------|-----------|-----------|-----------|------------|
| Избыточность R | 0.009845  | 0.009067  | 0.005456  | -0.005044  |

**Анализ:**

- При $n = 1$ кодирование Хаффмана отдельных символов даёт избыточность около 0.01 бит/символ, что соответствует теоретической оценке: для оптимального кода средняя длина превышает энтропию не более чем на 1 бит (в расчёте на символ здесь менее 0.01).
- С ростом $n$ избыточность уменьшается: $n=2$ даёт 0.00907, $n=3$ — 0.00546. Это объясняется тем, что блоки позволяют учесть некоторые статистические связи, и код становится ближе к истинному распределению.
- При $n = 4$ избыточность становится отрицательной ($-0.00504$). Это означает, что средняя длина кода на символ $L_{\text{sym}}$ оказалась **меньше** энтропии первого порядка $H$. Такое возможно, если между символами существуют корреляции: энтропия блока (на символ) ниже энтропии первого порядка. Код Хаффмана для блоков длины 4 эффективно использует эти зависимости, достигая средней длины даже ниже $H$. Таким образом, блочное кодирование превосходит посимвольное.

**Сравнение с теорией:**  
Теоретически, с увеличением длины блока средняя длина кода должна стремиться к истинной энтропии источника $H_\infty$. Полученные результаты качественно подтверждают это: избыточность (относительно $H$) убывает и даже становится отрицательной, что указывает на наличие зависимостей. Для точного количественного сравнения следовало бы оценить энтропию источника высших порядков, но это выходит за рамки задания.
